**新闻点赞 1.8 版本 —— TBE+ 自动化中心**

主界面按设计稿重做成企业级任务仪表盘，钉钉版补上使用引导、自动启动与 token 自动接管，
并且从代码层面与旧版 TBe+ 客户端彻底隔离。

## 钉钉版使用引导

新增「账号与连接」页，把首次使用拆成三步：

1. **一键准备**：自动查找并启动新版客户端 `TBeHome.exe`；
2. **打开 e+ → 新闻资讯**：没有登录态时自动把客户端带到前台，并给出明确提示；
3. **自动接管 token**：后台每秒轮询，读到 `tbea_art_token` 后自动校验、缓存，绿色「已接管」。

- 已有有效 token 时完全跳过客户端，直接纯 HTTP 运行；
- 自动准备失败不会卡住界面，转入后台继续等待，你可以正常操作；
- 支持手动填写 32 位 token 并在线校验；
- 显示客户端状态、token 摘要、执行方式（纯 HTTP / 客户端会话）。

## 与旧版 TBe+ 硬隔离

- 只接受 `TBeHome.exe`，代码里没有回退到旧版 `TBe.exe` 的分支；
- 钉钉模式的准备不会调用旧版客户端的查找 / 重启逻辑；
- 没有 token 时直接抛「必须接管 token」，绝不降级去驱动旧版客户端；
- 内存扫描只扫 `TBeHome.exe`，不扫 `TBe.exe`；
- 老版本模式保持原样。

## 任务概览仪表盘

- 顶部面包屑「运行中心 / 任务概览」、标题、状态胶囊、用时、设置入口；
- 四张指标卡：已处理（含总数与完成比例）、新点赞、原本已赞、未成功；
- 执行控制台：运行状态、`4 / 200 篇`、百分比、总进度条、三步流程、
  当前处理的资讯与时间；主按钮 / 试运行 / 停止视觉分层；
- 处理进度：已点赞 / 原本已赞 / 待处理 / 失败四段堆叠条 + 真实计数；
- 运行质量：成功率、平均耗时、当前批次，没有数据时显示「—」；
- 实时日志：时间 / 级别 / 进度 / 状态 / 资讯标题五列，支持全部/关键/问题筛选、
  搜索、暂停滚动、查看全部记录；
- 左侧导航新增「账号与连接」，底部状态卡显示 token 与执行方式；
- 窗口高度不足时自动收起「处理进度 / 运行质量」，把空间留给日志。

## 说明

- 本版提供免安装包 `TBeAutoLike-1.8.0-win64.exe`；
- 新版客户端是钉钉 CEF 壳，不开放调试端口，无法可靠模拟点击「新闻资讯」；
  程序已做到自动启动、前台提示和后台自动接管，你只需点开一次新闻列表；
- 未签名，SmartScreen 提示时点「更多信息 → 仍要运行」；
- 点赞算法、老版本流程、WebSocket/CDP 处理逻辑未改。
