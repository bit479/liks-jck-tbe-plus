# 1.8.3 更新说明

本次只改渲染与布局，业务逻辑未动。

## 切页卡白屏（重点）

- **根因**：原来每次切页都 `place_forget()` 掉旧页、再 `place()` 新页。首页控件多
  （4 张指标卡 + 执行控制台 + 处理进度/运行质量 + 实时日志表），重新 `place` 会让
  Tk 把整页子控件重新布局，实测 **任务设置 → 任务概览 要 190ms**，这段时间窗口是空的，
  看起来就是"卡白屏"。
- **修复**：4 个页面在构建时一次性 `place` 到同一位置**常驻叠放**，切换只做 `lift()`
  把目标页抬到最上层，不再重新布局、不再销毁/重建控件。
- 实测（纯切换，含 `update_idletasks`）：任务概览 ↔ 任务设置 双向都在 **11–19ms**，
  原来单向 190ms。切页不再有白屏，也没有 220ms 的位移动画。

## 运行质量一栏被遮挡

- **根因**：`mid` 行固定高 136px，右侧「运行质量」卡片 `fill=Y` 被锁在 136px，
  卡片 body 只有 134px，而内容（标题 + 图标 + 数值 + 标签）底部正好压在 134px——
  底部标签贴着卡片圆角边被裁掉。
- **修复**：`mid` 行高 136 → 148，`qrow` 增加下边距（`pady=(10, 6)`），
  实测卡片 body 146px、内容底部 140px，标签下方留出约 17px 空白。

## 圆角边缘

- 1px 边框不再用 Tk 的 `outline`（那是最"毛"的 1px 线算法），改成
  **"外扩 1px 的实心多边形打底 + 内层填充"** 叠出边框，圆弧仍为每角 18 段。
- 说明：Tkinter 的 Canvas 没有抗锯齿，无法像浏览器那样完全平滑；这已是纯 Tk
  能做到的最好效果。真正的 AA 只能用预渲染位图（9-slice）实现，属于较大改造。
