**新闻点赞 1.5 版本 —— 界面重做了一遍**

这一版**只动界面**：点赞逻辑、接口调用、配置项一行没改。
原来那个一屏塞五个框、看不出先点哪儿的窗口，换成了一套正经的桌面工作台。

## 新版长什么样

左侧深色导航 + 右侧白色卡片工作区，分三页：

| 页面 | 放什么 |
| --- | --- |
| **概览** | 四个指标（已处理 / 新点赞 / 原本已赞 / 未成功）、三个操作按钮、总进度条、每个板块的独立进度、实时日志 |
| **运行日志** | 完整过程记录，按级别上色，支持「全部 / 只看关键 / 只看问题」三档过滤，可导出 |
| **任务设置** | 新闻时间段、板块开关、每板块上限、快速模式、点赞后复查、连接信息，底部有「本次计划」摘要 |

## 变化

- **进度看得见了**：原来跑起来只有滚动的文字，现在每处理一篇就更新指标卡、板块进度条和「当前文章」。进度是从引擎日志里的 `[i/total]` 解析出来的，**没有改引擎**。
- **状态有标识**：右上角胶囊显示 空闲 / 运行中 / 正在停止 / 已完成 / 已停止，并记录用时；结束后「未成功」的卡片会变红并提示可以重跑补齐。
- **日志会分类**：板块标题蓝、小结绿、降速重试橙、失败红；逐条明细里的状态是彩色的、标题是灰的，不再一眼糊成一片。
- **设置不再挤在主页**：板块开关做成胶囊，时间段有「不限 / 近 7 天 / 30 天 / 90 天 / 1 年」快捷项，改哪一项底部「本次计划」会同步显示结果。
- **窄屏也放得下**：窗口窄时指标卡自动变两列、按钮文案收短；窗口矮时设置页出现滚动条，不压字号也不切内容。

## 顺手修掉的四个问题

1. **启动白屏 30 秒** —— 原来自检在主线程里扫 30 个调试端口，没开客户端时窗口看着像卡死。现在探测放后台，窗口立刻可用，状态区显示「检测中…」。
2. **偶发崩溃** —— 后台线程直接调 `root.after()`，会抛 `RuntimeError: main thread is not in main loop`。改成队列 + 主线程轮询。
3. **点「试运行」重复等 30 秒** —— 后台检测还没回来时又扫一遍端口，现在直接等那一次的结果。
4. **文字被切** —— 卡片高度原来写死，改一句文案就切字；现在按内容自适应。

## 升级方式

- 直接覆盖原来的文件夹即可，`config.json` / `state.json` **不用动**，配置项完全兼容。
- 版本号只是显示用；`python cli.py` 的所有参数保持不变。
- 喜欢老界面的话，`tbeplus/ui_classic.py` 是改造前的原样备份，把 `tbeplus/ui.py` 换回去就能退。
