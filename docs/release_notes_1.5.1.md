**新闻点赞 1.5.1 版本 —— 提供免安装 exe**

从这一版开始可以直接下载 `TBeAutoLike-1.5.1-win64.exe` 双击使用，
**不用装 Python、不用装任何依赖**。仍然保留源码方式，两种都行。

## 新增

- **单文件 exe**（约 12 MB）：`python build_exe.py` 即可重新打包，
  产物在 `dist/TBeAutoLike-<版本>-win64.exe`
- `exe --selftest`：不建窗口，把版本、配置目录、图标资源、tkinter 版本写进
  同目录的 `selftest.log`，交付后远程排查用
- exe 的 `config.json` / `state.json` 就放在 exe 旁边（不是临时解包目录），
  拷走 exe 时把这两个文件一起拷走即可保留配置和登录缓存

## 修复（打包后才会暴露的问题）

1. **配置目录**：onefile 模式下 `__file__` 指向 `%TEMP%` 的解包目录，配置写在那里，
   程序一关就丢。改为按 `sys.frozen` 判断，以 exe 所在目录为准。
2. **黑框闪烁**：`--windowed` 的 exe 自身没有控制台，调用系统命令行查进程时会闪一个
   黑窗口。子进程加 `CREATE_NO_WINDOW`。
3. **窗口被裁**：某些 DPI 缩放/远程桌面环境里，窗口管理器会把窗口压得比请求更小，
   而 Tk 仍按原尺寸排版，右侧内容被裁掉。现在布局改按**内容区实际宽度**判断几列显示，
   映射完成后还会用 Win32 读一次真实客户区做校正。

## 用法

```
双击 TBeAutoLike-1.5.1-win64.exe
→ 概览页点「准备并接管客户端」→「试运行」→「开始点赞」
```

首次运行如果提示找不到 TBe.exe，按弹窗选一次安装目录里的 TBe.exe，之后会记住。

## 说明

- 界面与 1.5.0 相同，本版只加打包能力并修上面三处
- 源码方式完全不受影响：`python -X utf8 app.py` 仍然可用
- 未签名：Windows SmartScreen 可能提示"未知发布者"，点"更多信息 → 仍要运行"即可
