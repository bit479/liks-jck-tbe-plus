# 1.8.1 更新说明

本次修两处实际使用时比较影响手感的问题：左上角重复的品牌，以及运行时不断闪出
的命令窗口。业务逻辑、点赞流程不变。

## 界面

- **左上角重复的品牌合并为一处**：原来窗口标题栏和左侧导航各画了一遍
  图标 + 「TBE+ 自动化中心」，上下紧挨着像"重影"。现在只保留顶部这一处。
- **标题栏改为左右分色**（对齐设计稿）：左侧是与侧边栏同宽的深色区（放品牌，
  和侧边栏连成一列），右侧浅色区放最小化 / 最大化 / 关闭。
- 顺带给窗口按钮加了浅底深色图标支持，浅色标题栏上也能看清。

## 运行中不再弹命令窗口

之前运行时（尤其钉钉版）会一直闪出黑色命令窗口，原因有两个：

- 钉钉版每 2 秒轮询一次客户端进程，用的是 `tasklist` 子进程；
- 老版本判活 / 找 exe / 查端口占用，用的是 PowerShell 子进程。

这次新增 `tbeplus/winproc.py`，用纯 Win32 API 完成这些查询（零依赖、零子进程）：

- `CreateToolhelp32Snapshot` 枚举进程；
- `QueryFullProcessImageNameW` 取进程完整路径；
- `GetExtendedTcpTable`（iphlpapi）查端口归属；
- `winreg` 读卸载项 / App Paths；
- 自己解析 `.lnk` 的 LinkInfo 取快捷方式目标。

替换后：

- 判活、找 `TBe.exe` / `TBeHome.exe`、端口占用者、关闭客户端全部零子进程；
- 钉钉版的进程轮询不再起 `tasklist`，运行时不再有命令窗口闪现；
- 启动客户端的 `Popen` 补上 `CREATE_NO_WINDOW` 兜底。
