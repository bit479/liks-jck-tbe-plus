**新闻点赞 1.7 版本 —— 统一动效与版本入口图标**

界面交互更顺滑了：页面切换、按钮、开关、导航、进度条和日志都有克制的过渡动画，
整体感觉更像一个打磨过的桌面软件，但动画存在感很低，不会拖慢操作。

## 动效

- **统一节奏**：悬停 150ms、按压 100ms、页面切换 220ms、进度条 280ms，
  全部走同一条 `cubic-bezier(0.22, 1, 0.36, 1)` 缓动曲线；
- **页面切换**：8px 轻位移进入，不闪白、不跳动，任务状态和滚动位置不丢；
- **首屏**：每个版本第一次进入概览时，四张统计卡以 40ms 交错淡入，之后切回不重播；
- **按钮**：悬停平滑变色、按下轻微内缩，禁用状态立即明确；
- **统计卡**：数值变化时短暂带语义色再回归，高频刷新不反复触发；
- **进度条**：平滑推进到真实目标，新一轮任务归零即时，不编造百分比；
- **日志**：新行 150ms 轻淡入；高频时自动降级（0.5 秒超 8 行就停），不卡顿、不乱序；
- **减少动态效果**：Windows「关闭动画效果」或设 `TBE_REDUCED_MOTION=1` 时，
  所有动画即时完成，任务与数据更新零延迟。

技术上是标准库 `tbeplus/motion.py`（约 200 行）：全部动画共用一个 16ms 时钟、
空闲即停，没有动画库依赖，没有长期定时器。

## 版本入口图标

- 「老版本 TBe+」卡片现在用 `旧版tbe+图标.png`；
- 「钉钉版 TBe+」卡片现在用 `ding-tbea.png`；
- 程序图标（窗口/任务栏/exe）不变，仍是眨眼宝宝点赞图标。

## 稳定性

- 动画只改 UI 表现，不触发任务、网络或配置写入；
- 启动、接管、试运行、正式执行、停止的流程与 1.6 完全一致；
- 点赞引擎（`engine.py`）、客户端接管（`client.py`）、接口（`newsapi.py`）、配置（`config.py`）零改动。
