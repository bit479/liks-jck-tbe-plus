# UI 回归测试清单

## 1. 当前覆盖结论

- 仓库现有 `tests/test_websocket.py`：覆盖 WebSocket 握手、掩码、大消息、分片、ping/pong、事件缓存和 CDP 调用；**不覆盖 UI**。
- `_shot.py`：可截取 select/home/log/settings/connect，支持窗口尺寸和版本选择；**只是截图工具，不是测试**。
- 当前没有页面、组件、运行动画、DPI、窗口、业务桥接或打包后 UI 的自动化回归。
- 本清单是后续实施验收标准；本阶段未执行真实点赞，也未修改测试。

## 2. 测试分层和安全约束

| 层级 | 工具/方式 | 目的 |
| --- | --- | --- |
| L1 纯逻辑 | 标准库 `unittest` 或获批测试框架 | 日志解析、状态机、RunRequest、设置联动、统计 |
| L2 组件 | Qt 测试接口；Tk 降级用事件模拟 + 状态断言 | 控件状态、键盘、焦点、输入验证 |
| L3 页面集成 | fake engine/client/token，内存日志 | 页面导航和完整状态流，不访问真实系统 |
| L4 视觉 | 固定尺寸截图 + 基线差异 + 人工复核 | 切字、重叠、对比度、图标、DPI |
| L5 Windows/打包 | 人工 + 脚本辅助 | 多屏、窗口管理、exe、自包含资源 |

**强制安全约束**：默认禁止真实点赞、重启真实客户端、读取真实 token、写真实 config/state。使用临时目录、虚拟凭证和 fake 适配器。真实写操作只能在隔离账号、明确人工审批后单独执行，不属于常规回归。

## 3. 固定测试矩阵

### 窗口与环境

- 尺寸：`900×700`（最小附近）、`1280×800`（常规）、`1600×1000`（宽屏）、`900×620`（低高度边界）。
- DPI：100%、125%、150%、175%、200%。
- 版本：老版本、钉钉版。
- 动效：正常、Windows 关闭动画、`TBE_REDUCED_MOTION=1`（Tk 或兼容开关）。
- 数据：空、单板块、多板块、长中文/英文标题、大日志、失败混合、无日期文章。
- 页面状态：首次选择、未连接、准备中、就绪、运行、停止中、已停止、成功、失败。

## 10. 验收记录格式

每次执行至少记录：构建 commit、OS、Python/GUI 框架版本、DPI、窗口尺寸、测试 ID、实际结果、截图/日志路径、是否阻塞发布。失败项必须关联问题 ID；未执行不能标记通过。真实业务写入测试另列审批人、环境和结果，不与常规 UI 回归混合。
