# Linear 风格设计规范

## 1. 定位与原则

本规范借鉴 Linear 的密度、层级、组件克制感和交互反馈，并参考 Raycast 的键盘效率、Vercel 的中性色与排版纪律；**不复制其业务结构、品牌资产或页面布局**。

TBE+ 是执行真实写操作的内部桌面工具，因此优先级为：

1. **状态清楚**：当前版本、连接状态、运行/停止、成功/失败不可含糊。
2. **主任务优先**：准备 → 试运行 → 正式运行 → 查看结果，不被装饰和次要指标打断。
3. **深色但不纯黑**：用相邻灰阶和 1px 细线分层，不用大面积蓝紫卡片。
4. **紧凑且可读**：减少无效留白，但不牺牲中文行高、点击区域和焦点可见性。
5. **动效解释状态**：只表现悬停、切换、进度和反馈，不做秀场动画。
6. **风险操作克制**：正式点赞、接管客户端、切换版本、退出运行任务使用明确确认，不靠红色装饰制造紧张感。

禁止：廉价渐变、彩色玻璃卡、过量阴影、无意义插画、持续呼吸灯、每次切页大幅滑动、仅靠颜色表达状态。

## 2. 设计令牌

以下为 100% 缩放下的建议初值。实现时应建立语义命名；页面不得自行发明近似色。

### 2.1 深色中性色

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `bg.app` | `#0E0F12` | 应用最底层 |
| `bg.sidebar` | `#111216` | 侧栏，与主区仅轻微区分 |
| `bg.canvas` | `#131418` | 主工作区 |
| `bg.surface` | `#17191E` | 面板、表单分组 |
| `bg.elevated` | `#1C1E24` | 对话框、菜单、浮层 |
| `bg.hover` | `#21232A` | 悬停 |
| `bg.active` | `#272A33` | 选中/按下，不使用整块高饱和蓝 |
| `bg.subtle` | `#14161B` | 表头、日志、代码区 |
| `border.default` | `#292C33` | 常规分隔线 |
| `border.strong` | `#3A3E48` | 输入框、强边界 |
| `text.primary` | `#F0F1F4` | 主文本，避免大面积纯白 |
| `text.secondary` | `#A6ABB8` | 正文辅助、标签 |
| `text.muted` | `#767C8A` | 次要说明；不用于关键操作 |
| `text.disabled` | `#555B67` | 禁用文本，需配合禁用形态 |

### 2.2 强调色与语义色

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `accent.default` | `#858AF0` | 主按钮、焦点、当前关键状态 |
| `accent.hover` | `#989CF3` | 主按钮悬停 |
| `accent.pressed` | `#7277D8` | 按下 |
| `accent.subtle` | `#24263A` | 低强度选中/标签背景 |
| `accent.text` | `#AEB2F6` | 深底上的强调文字 |
| `success.default` | `#63A884` | 已完成/有效 |
| `success.subtle` | `#192B24` | 成功弱背景 |
| `warning.default` | `#C2A366` | 等待、停止、配额 |
| `warning.subtle` | `#30291B` | 警告弱背景 |
| `danger.default` | `#D67E82` | 失败、危险操作 |
| `danger.subtle` | `#321F24` | 错误弱背景 |
| `info.default` | `#75A7D8` | 普通提示 |

- 主按钮可使用 `accent.default` + 深色文字，前提是实测对比度通过；否则采用浅色文字版本并固定为唯一主按钮样式。
- 正文文本目标对比度至少 4.5:1，大文本和关键图形至少 3:1；`text.muted` 不用于错误原因、连接状态等关键内容。
- 状态同时使用图标/文案，不仅用绿、黄、红。
- `accent.subtle` 等是实色令牌，避免 Tk 路线依赖透明度。

### 2.3 字体与排版

| 样式 | 逻辑字号 | 行高 | 字重 | 用途 |
| --- | ---: | ---: | --- | --- |
| `display` | 24px | 32px | 600 | 仅版本欢迎页，可选 |
| `pageTitle` | 20px | 28px | 600 | 页面标题 |
| `sectionTitle` | 14px | 20px | 600 | 分组标题 |
| `body` | 13px | 20px | 400 | 正文、表单 |
| `bodyStrong` | 13px | 20px | 600 | 关键值、按钮 |
| `caption` | 12px | 18px | 400 | 辅助说明、表格元信息 |
| `micro` | 11px | 16px | 500 | 分组标签，限制使用 |
| `metric` | 24px | 28px | 600 | 关键指标，使用等宽数字 |
| `mono` | 12px | 19px | 400 | 日志、时间、token 摘要 |

- Windows 中文首选 `Microsoft YaHei UI`，拉丁/数字可用 `Segoe UI`，等宽用 `Cascadia Mono`、回退 `Consolas`。
- 不默认下载或捆绑 Inter；若未来引入，须单独确认资产许可和打包策略。
- 字体回退必须覆盖中文、图标和等宽数字；禁止用 Emoji 字体替代功能图标。
- 数字指标启用 tabular numbers（框架支持时），防止计时和计数跳动。

### 2.4 间距、尺寸、圆角和阴影

采用 4px 基础网格：

```text
space.1 = 4    space.2 = 8    space.3 = 12   space.4 = 16
space.5 = 20   space.6 = 24   space.8 = 32   space.10 = 40
```

| 项目 | 规范 |
| --- | --- |
| 侧栏 | 默认 232px；紧凑 208px；不在本阶段增加折叠业务 |
| 窗口标题栏 | 40px；若用原生标题栏则服从系统 |
| 页面工具栏 | 56px，包含标题、状态和上下文操作 |
| 页面外边距 | 常规 24px；宽屏 32px；窄窗口 16px |
| 分组间距 | 24px；组内行距 12px/16px |
| 控件高度 | 紧凑 28px；默认 32px；主操作可用 36px |
| 图标按钮 | 28×28 或 32×32；功能图标 16×16 |
| 圆角 | 小标签 4px；控件 6px；面板/菜单 8px；对话框 10px |
| 边框 | 默认 1px；焦点外环 2px |
| 阴影 | 只用于浮层：`0 8 24 #00000040` 级别；面板不用大面积阴影 |

## 3. 页面骨架

```text
┌ 原生/自绘窗口标题栏：品牌、版本切换、窗口控制 ┐
├──────────┬───────────────────────────────────┤
│ 侧栏      │ 页面工具栏：标题 / 状态 / 页面操作 │
│ 运行中心  ├───────────────────────────────────┤
│ 配置管理  │ 主工作区                           │
│          │ 分组、表单、日志；按需滚动           │
│ 连接摘要  │                                   │
└──────────┴───────────────────────────────────┘
```

- 品牌只出现一次；版本切换是真实状态入口，不重复设置页和侧栏文案。
- 页面工具栏只保留当前页相关操作；窗口控制与业务操作不可混在同一按钮组。
- 主区优先无卡分区；只有需要边界或独立操作的模块使用 `bg.surface` 面板。
- 最大内容宽度建议 1440px，超宽屏增加外侧留白，不无限拉长日志和表单行。

## 4. 核心组件

### 4.1 按钮

| 变体 | 外观 | 用途 |
| --- | --- | --- |
| Primary | 低饱和紫底，单页最多一个主操作 | 开始任务、保存并校验 |
| Secondary | `bg.surface` + `border.strong` | 试运行、准备、导出 |
| Ghost | 透明底，悬停 `bg.hover` | 工具栏、低优先级操作 |
| Danger | 默认深底红字细边；确认弹窗内可用红底 | 停止、危险确认 |
| Link | 无容器，强调文字 | 查看全部日志 |

所有按钮必须具有 default/hover/pressed/focus/disabled/loading 状态。禁用仍需可读，加载时保持原宽度，避免布局跳动。图标在文字左侧，图标按钮必须有 Tooltip 和可访问名称。

### 4.2 输入框与表单字段

- 高度 32px，`bg.subtle`，1px `border.strong`，圆角 6px。
- Focus：边框 `accent.default` + 2px 低强度焦点外环；Error：边框 `danger.default`，错误文案在字段下方。
- Placeholder 是独立绘制状态，不得写入真实值；禁用、只读、掩码、搜索清除按钮均需统一。
- 每个字段由 `label + control + hint/error` 组成；说明不横向挤在标题右侧。
- 日期格式即时提示，正式运行前验证；token 默认掩码，已保存状态用摘要表示。

### 4.3 侧栏导航

- 行高 32px，左右内边距 12px，图标 16px，图标文字间隔 8px。
- 默认文字 `text.secondary`；hover 仅背景微亮；active 使用 `bg.active` + `text.primary`，可加 2px 左侧强调条。
- 不使用当前版本的整块饱和蓝底，不在 active 时突然加粗导致宽度变化。
- 分组标题 11px，上下留白充足；底部连接摘要只显示状态与短说明，不使用复杂状态卡。

### 4.4 面板、指标与进度

- 面板是分组容器，不是每个数字的彩色卡片。
- 指标可并列于一条简洁统计区：标签 12px、数值 24px、单位 12px；不用左侧彩色条。
- 总进度条高 4px，轨道 `border.default`，填充 `accent.default`；失败分布在图例和文本中说明。
- “处理进度/运行质量”默认折叠为次级详情；窗口高度不足时优先保留主操作和日志。
- 步骤状态用 `idle/active/done/error` 图标 + 文案；错误不能被后续成功动画覆盖。

### 4.5 日志与表格

- 表头固定在顶部，行高 28px；时间、进度、计数用等宽字体。
- 时间 / 级别 / 进度 / 状态 / 标题列可调整宽度；标题过长单行省略并提供完整 Tooltip/详情。
- 日志级别用文字和图标，不仅用颜色；搜索、筛选、暂停滚动、复制、导出状态清晰。
- 空状态只保留一个线性图标、标题和一步引导；错误状态提供重试或打开连接页。
- 大数据使用有界模型/虚拟化，不能因筛选重复复制整份文本。

### 4.6 对话框、Toast、Tooltip

- Dialog：宽 420–520px，标题、具体后果、主/次按钮；默认焦点落在安全操作，Esc 关闭非强制流程，Tab 不逃逸。
- 正式点赞确认说明目标范围；接管确认明确“会重启客户端”；退出确认明确“当前任务将中断”。
- Toast：用于复制成功、导出成功、配置已重载等轻反馈；3–4 秒消失，错误需可追踪到日志，不用 Toast 替代关键状态。
- Tooltip：500ms 左右延迟，仅补充图标含义和完整文本，不承载必要操作。

## 5. 动效与反馈

| 场景 | 时长 | 曲线/方式 |
| --- | ---: | --- |
| Hover 颜色 | 80–120ms | ease-out |
| 按压 | 60–80ms | 立即响应，无布局缩放 |
| 导航/控件选中 | 120ms | 背景/文字颜色插值 |
| 页面内容进入 | 120–160ms | 透明度 + 4px 位移，仅框架支持时 |
| 菜单/Tooltip | 100–140ms | 淡入，不大距离滑动 |
| 进度更新 | 160–240ms | 真实目标立即保存，显示平滑跟随 |
| 成功/失败状态 | 120–160ms | 颜色/图标过渡，不闪烁 |

- 不在首屏对多张卡做交错网点动画，不为每条高频日志强制淡入。
- 尊重 Windows 减少动态效果和应用开关；关闭时同步到终态，绝不延迟业务事件。
- 动画不得造成按钮位置变化、文本宽度变化、隐藏页获取焦点或主线程高频全量重建。

## 6. 图标与资产

- 功能图标统一 16×16 网格、1.5px 笔画、圆角端点；常用 20/24px 仅用于空状态。
- 使用一组明确的线性 SVG 图标（自绘或许可明确的集合），图标名按语义管理，如 `play`、`stop`、`settings`、`link`、`warning`。
- PySide6 渲染 SVG 并按状态着色；Tk 降级方案预渲染 100/125/150/200% PNG，不能依赖 MDL2 私有码位。
- 品牌图标与 UI 功能图标分离；不在每个面板重复品牌。
- 新资产须记录来源和许可，截图使用虚拟账号、虚拟 token 和虚拟标题。

## 7. 响应式、DPI 与键盘

### 建议断点

| 可用主区宽度 | 行为 |
| --- | --- |
| `< 720px` | 页面边距 16px；表单单列；次要操作进溢出菜单；日志保留搜索和关键筛选 |
| `720–1059px` | 指标保持 4 列但隐藏次要说明；设置两列可转单列；不隐藏必要准备入口 |
| `≥ 1060px` | 标准 24/32px 边距，统计/详情可双列 |

高度不足时先折叠次级分析，不缩小正文，不把日志压到不可用。设置/连接页允许纵向滚动。

### DPI 验收

覆盖 100/125/150/175/200%，以及跨不同 DPI 显示器移动。所有文本不得切字，图标清晰，焦点和边框保持可见，窗口最大化回到当前显示器。

### 键盘基线

- Tab/Shift+Tab 顺序符合视觉顺序；Enter/Space 激活按钮和开关；方向键操作单选组和步进器。
- Esc 关闭可取消弹窗；Ctrl+F 聚焦日志搜索；Ctrl+C 在日志中复制所选/当前可见内容。
- 焦点环不可被 hover 替代，隐藏页和禁用控件不得获得焦点。

## 8. 验收原则

每个组件需提供状态矩阵，每个页面需提供空、就绪、运行、停止、成功、失败截图或等价可验证状态。验收不仅看“像 Linear”，还必须验证：功能等价、日志口径一致、凭证不泄露、主线程不阻塞、减少动态效果有效、键盘可达、最小窗口和高 DPI 无切字。
