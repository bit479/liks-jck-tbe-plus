**新闻点赞 1.7.1 版本 —— 修两处界面边缘问题**

这一版只修界面细节，业务逻辑与点赞流程完全没动。

## 修复

- **关闭按钮右侧的白边、窗口右/下边缘发亮**
  无边框窗口四周有 4px 拖拽热区，原来右、下两边用了浅色，还铺到了深色标题栏
  和深色侧栏上，所以看起来像漏白。现在热区按区域拆开：标题栏与侧栏部分深色、
  内容区浅色，右侧标题栏不再放热区，也不会压住关闭按钮。

- **左下角「客户端状态」说明文字被截**
  状态卡高度原来写死，说明两行装不下；长句还会从右侧被裁。现在卡片按内容
  自动撑高，说明文字会自动折行，并在每次状态变化后重新量一次高度。

- 说明文案顺带改短了（「可用 token 免客户端运行」），两行读起来更自然。

## 验证

- 1280×880 采样四边像素：标题栏右端 `#172536`、内容区右端 `#F3F5F8`、
  侧栏左下 `#172536`、版本页四角 `#F3F5F8`，没有白边或杂色；
- 状态说明完整落在卡片内，底部两个按钮不溢出侧栏；
- 三页切换、板块开关、配置写回、无客户端试运行复位全部通过；
- 全模块编译通过，1.7 的动效与图标不受影响。
