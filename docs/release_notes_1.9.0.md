# 1.9.0 更新说明

本次是**界面改版**：把「深色侧栏 + 浅色卡片」的管理后台风格，换成一套统一的
深色工作台；自动化流程、配置格式、客户端接管方式都没有改动。

## 整体观感

- 全深色：主背景 `#111318`、面板 `#181B22`、悬停 `#292E38`、边框压到低对比度，
  不再是"左边深色、右边一片白"。
- 强调色统一为低饱和紫 `#8B83F6`，只出现在主操作、选中态和阶段进度上。
- 圆角收成三档：卡片 10、控件 6、胶囊 999；层级靠 1px 边框和留白区分，
  没有渐变、没有大面积彩色卡片、没有多余阴影。
- 字号分级固定：页面标题 18、卡片标题 13、正文 12–13、辅助说明 11，
  统计数字 32 并开启等宽数字对齐。

## 侧栏与导航

原来 4 项平铺，现在分三组共 7 项：

| 分组 | 页面 |
| --- | --- |
| 工作空间 | 任务概览、运行日志 |
| 自动化管理 | 任务设置、配置管理、账号与连接 |
| 系统 | 版本信息、偏好设置 |

- 宽 220px，选中态只有一层极淡底色 + 强调色图标 + 白色文字，不做整行高亮块。
- 悬停有约 130ms 的底色过渡，按下再深一档，禁用统一走灰字。
- 底部固定：客户端连接状态卡（状态点 + 说明 + 手动刷新）与版本行。
- 版本选择器改成带下拉箭头的可点条目，hover / 按下都有反馈。

## 首页

- **统计四卡**：已处理资讯 / 新增点赞 / 原本已赞 / 执行失败。数字成为视觉中心，
  **没有数据就是 0**，不再显示横线占位；每张卡带一句辅助说明（如「共 12 篇」
  「待点赞 3」「无失败」），全部来自真实运行数据。
- **执行面板**收成一条：运行状态、已处理 / 总数、待处理、成功、失败、用时、
  进度条，与「开始点赞 / 试运行 / 停止 / 准备并接管客户端」同屏，不用滚动。
  停止按钮只在任务运行时可用。
- **五阶段紧排条**：客户端连接 → 获取资讯 → 资讯筛选 → 执行点赞 → 结果统计，
  每段有未开始 / 进行中 / 已完成 / 失败四种状态，由真实运行事件驱动
  （不是静态装饰）。
- **实时日志改成四列事件表**：时间 / 级别 / 来源 / 内容。级别按 INFO / OK / KEY /
  WARN / ERR 分色；支持全部 / 成功 / 关键 / 警告 / 错误五档筛选、关键词搜索、
  暂停自动滚动、复制、导出为 txt、清空；单行过长自动截断，不会撑出横向滚动条。
  空日志时显示引导提示，而不是一个巨大的空白框。

## 新增页面

「配置管理」「版本信息」「偏好设置」三个页面本次补上，**只读展示真实信息**
（当前版本、执行方式、板块与配置摘要、动效开关状态），不含任何演示数据。
真正的编辑能力留到后续版本，避免在没接好配置读写前做出"看起来能改、其实没生效"的界面。

## 修掉的问题

- 新版页面常量 `VERSION` 覆盖了包里的 `__version__`，导致界面显示 `vVERSION`；
  改名为 `VERSION_PAGE`。
- 日志表补了 3000 行上限，长任务不再无限增长内存。
- 侧栏底部两个入口按钮过窄、文字被压成两行的问题。
- 窄窗口下统计卡说明文字与数字重叠的问题。

## 关于新界面（重要）

仓库里还有一套 **PySide6 新版界面原型**（入口 `app_qt.py`，独立于 `app.py`）：

- 全部控件用 `QPainter` 自绘：圆角是真正的矢量抗锯齿，1px 边框落在半像素上；
- 图标换成 27 个 SVG，矢量缩放，不再用字体码位；
- 按 Windows Per-Monitor V2 处理高 DPI，实测 100% / 125% / 150% / 200% 四组
  无重叠、无裁切；
- 首页已含侧栏、顶栏、统计四卡、执行面板、五阶段、事件列表与交互（筛选/搜索/
  暂停/复制/导出/清空均可用）。

但它**还没接任务引擎**：点「开始点赞」只会提示"P2 接入"，不会真的跑任务。
所以本次安装包仍是 Tkinter 版，圆角依旧没有抗锯齿——这是 Tk Canvas 的硬限制，
不是没修。等新界面接完引擎与全部页面，再作为正式界面发布。

## 已知限制

- 窗口四角在 Tk 版仍是直角（无边框窗口拿不到 DWM 圆角）。
- 设置页内容较长，矮窗口（如 900×700）需要往下滚动。
- 手动填写 token 的输入框是密码掩码，但仍可被截图工具看到明文剪贴板内容，
  建议在私密环境操作。

## 安装包

`TBeAutoLike-1.9.0-win64.exe`（未签名，SmartScreen 提示时点「更多信息 → 仍要运行」）。

- 运行时不需要装 Python，也不需要任何第三方库；
- `config.json`（可选）放在 exe 旁边即可；
- 从 1.8.x 升级直接覆盖 exe 即可，配置与状态文件不用动。
