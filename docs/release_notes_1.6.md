**新闻点赞 1.6 版本 —— 两个版本分开跑，界面重做**

之前两个版本混在同一个概览页里：板块列表里同时挂着「新闻资讯」和「钉钉版e+新闻资讯」，
配置和进度互相牵连。这一版把它们彻底分开了，顺手按 `UI修改.txt` 把界面又过了一遍。

## 进入软件先选版本

| 版本 | 板块 | 说明 |
| --- | --- | --- |
| **老版本 TBe+** | 新闻资讯 / 开讲了 / 进出口公司新闻资讯 | 传统桌面客户端，需要重启并接管客户端 |
| **钉钉版 TBe+** | 钉钉版e+新闻资讯 | 新版钉钉套壳的「新闻资讯」，各公司订阅号全部资讯 |

- 选择页是两张可点的大卡片，进去之后在「任务设置 → 版本」里随时能换；
- 每个版本只显示自己的板块，进度、勾选、汇总都跟着走，**不会串味**；
- 引擎没改：还是用 `portal_cards` / `dingtalk_news` / `skip_session_by_default` 控制跑哪些板块。

## 沉浸式标题栏

- 去掉系统标题栏，自绘 42px 深色栏，和左侧导航同一底色，连成一片；
- 自带最小化 / 最大化（还原）/ 关闭，关闭按钮悬停变红；
- 支持拖动、双击最大化、八个方向拖边缩放；
- 无边框窗口默认不在任务栏出现，已用 `WS_EX_APPWINDOW` 补回来；
- **标题栏不再显示版本号**，版本号移到「任务设置 → 版本」。

## 新图标

用 `眨眼宝宝点赞图标` 重做了整套图标：窗口、任务栏、exe、界面内 logo 全部换掉，
四角白底抠成透明，生成 7 个尺寸的 ico。

## 按 UI 修改清单做的调整

- **标题区**：压到 94px，标题 22px、说明 13px，右侧状态胶囊与任务状态同步（不再被下面的卡片切掉）。
- **统计卡**：数字 22pt（约 29px）为视觉焦点，标签 10pt，左侧语义色条。
- **执行区**：只有「开始点赞」是主蓝色；「准备并接管客户端」按连接状态改文案（已接管 → 重新接管客户端）；运行中三个按钮禁用，只放开「停止」。
- **进度**：8px 高，右侧显示「已处理 / 总数 · 百分比」，**总数未知时只显示已处理数，不编造百分比**。
- **板块状态**：待处理（灰）/ 处理中（蓝）/ 已完成（绿，进度条同步变绿）/ 失败（红）。
- **日志**：改成「时间 + 级别 + 消息」三列的事件查看器，INFO 灰 / OK 绿 / WARN 橙 / ERR 红；
  逐条明细只给状态上色、标题保持中性；新增「暂停滚动」「复制」；空状态是图标 + 两行引导。
- **设置页**：按业务分块（版本 / 时间段 / 板块 / 运行参数 / 连接信息 / 本次计划），矮窗口自动滚动。

## 兼容性

- `config.json`、`state.json` 格式没变，直接覆盖 exe 或源码目录即可；
- `python cli.py` 的所有参数保持不变，命令行模式不受影响；
- 业务逻辑（点赞判断、跳过已赞、遍历、重试、停止）一行没改。

## 验证

- 启动落在版本选择页；两个版本各跑各的板块，切换后配置正确（老版本 `portal_cards` 两项、钉钉版 `dingtalk_news` 单开）；
- 板块勾选联动进度行与配置；日志时间/级别/复制/暂停滚动；窗口拖动/缩放/最大化/还原；设置页 6 张卡片均有内容高度；
- 无客户端时点「试运行」→ 明确提示并回到「已完成」，按钮状态恢复；
- exe 打包后 `--selftest` 通过，界面正常。
